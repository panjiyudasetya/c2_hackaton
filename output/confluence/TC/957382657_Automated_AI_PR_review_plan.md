# Automated AI PR review plan

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/957382657  

## Content

This document outlines the strategic plan for developing and deploying an AI-powered Pull Request (PR) Reviewer. The primary objective is to create a system that can automatically review all pull requests, ensuring that at least 80% of the issues identified by human reviewers are also flagged by the AI. The focus will be on maintaining high coding standards, enhancing documentation, identifying potential bugs, ensuring adequate testing, and improving overall code quality. The plan includes measurable key results, a detailed five-month timeline, and specific activities aimed at achieving the main goal. Through this initiative, we aim to streamline the code review process, reduce manual effort, and enhance the quality of our software development practices.

## 🎯 **Main Goal**

> **Build and deploy an AI PR Reviewer that automatically reviews 100% of pull requests and catches at least 80% of the issues a human reviewer would flag — focusing on enforcing basic coding standards, documentation, potential bugs, missing tests, and general code quality improvements.**

---

## 🔑 **Key Results (Measurable Success Criteria)**

| # | Key Result | How It’s Measured | Target |
| --- | --- | --- | --- |
| **KR1** | AI detects ≥80% of human-identified issues across documentation, testing, and code quality. | We will be creating a sample set of PR’s and letting a human review them and an AI tool. We will be comparing the results and seeing if the AI missed any problems the human did notice or the other way around. | ≥80% overlap |
| **KR2** | False positive rate (irrelevant or incorrect comments) below 20%. | We will be creating a sample set of PR’s and letting the AI tool review them. A human developer will go over all PR’s and see how many false positives were generated by the AI. | ≤20% |
| **KR3** | 100% of PRs automatically receive AI review feedback. | We will be keeping track of which projects are supported by the AI tool and which are not. | 100% coverage |

## 🚀 Next Steps

As we continue to improve the performance and reliability of our AI PR Reviewer, the next phase of our initiative will be to explore the feasibility of allowing certain pull requests to be reviewed exclusively by AI.

Key discussion points and actions for this next step include:

* Identifying types or categories of PRs that may be suitable for AI-only review (e.g., minor documentation changes, non-critical code updates).
* Defining clear criteria and safeguards to ensure that AI-only reviews do not compromise code quality or security.
* Gathering feedback from developers on the effectiveness and trustworthiness of AI-only reviews.
