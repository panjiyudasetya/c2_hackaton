# Back-end security vulnerabilities

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/163282945  

## Content

**Conclusion:** we need to improve escaping input for content that ends up in PDFs, e.g. safety checklists. And validate the thymeleaf configuration, checking whether it allows remote code execution.
