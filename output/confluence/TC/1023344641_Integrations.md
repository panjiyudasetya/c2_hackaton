# Integrations

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/1023344641  

## Content

This section brings together all AI-powered **integrations embedded into Teqplay tools and platforms**.

**Integrations** are AI capabilities built into existing tools such as:

* Confluence
* Monday.com
* Power BI
* Email tools
* Internal dashboards
* Reporting environments

They help automate tasks such as summarizing data, generating insights, drafting text, or surfacing recommendations directly inside the tool.

Each integration page explains:

* **What it does**
* **How it works** (simple workflow)
* **Who uses it**
* **Status** (success, pilot, idea)
* **Contacts**

## **How to Use This Section**

1. Open the **Integrations Collection**
2. Select an integration you want to use (e.g., Copilot with Power BI)
3. Read the **How It Works** section on the integration page
4. Try it in your own tool (Power BI, Confluence, etc.)
5. Reach out to the contact if you need support

---

## **Contribute a New Integration**

If you’ve connected AI into a tool and it’s beneficial to others:

1. Click **+ Add entry** on the **Integrations Collection**
2. Enter the the Integration Name, Contact, Domain
3. Type in the Integration Name on Integrations Page field, click **+ Create page**
4. This will create a page using the Integration Page template. Click on the link to go to this new page. Refresh might be needed.
5. Fill in the details (what it does, how it works, etc.)
