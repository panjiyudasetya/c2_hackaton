## ais-stream:diff

*Account: ais-stream*

## event-stream

> event-stream contains all kinds of events generated by event monitors or applications, and is used to share derived state.

*Account: events*

| Subjects | Publishers | Consumers |
| --- | --- | --- |

| `event.anchored.end.anchor.{poma_id}` `event.anchored.start.anchor.{poma_id}` | [anchor-monitor](#anchor-monitor) | [event-converter](#event-converter) [event-history-processor](#event-history-processor) |
| `event.area.end.berth.{poma_id}` `event.area.start.berth.{poma_id}` | [area-monitor](#area-monitor) | [berth-monitor](#berth-monitor) [event-converter](#event-converter) [event-history-processor](#event-history-processor) [ship-history-processor](#ship-history-processor) |
| `event.area.end.{area_type}.{poma_id}` `event.area.start.{area_type}.{poma_id}` | [area-monitor](#area-monitor) | [event-converter](#event-converter) [event-history-processor](#event-history-processor) |
| `event.berth-confirmed.end.berth.{poma_id}` `event.berth-confirmed.start.berth.{poma_id}` `event.berth-unique.end.berth.{poma_id}` `event.berth-unique.start.berth.{poma_id}` | [berth-monitor](#berth-monitor) | [event-converter](#event-converter) [event-history-processor](#event-history-processor) |
| `event.encounter.end.{encounter_type}` `event.encounter.start.{encounter_type}` | [encounter-monitor](#encounter-monitor) | [event-converter](#event-converter) [event-history-processor](#event-history-processor) |
| `event.ship-moving.end` `event.ship-moving.start` | [ais-diff](#ais-diff) | [anchor-monitor](#anchor-monitor) [event-converter](#event-converter) [event-history-processor](#event-history-processor) |
| `event.true-changed.destination` | [port-matcher](#port-matcher) | [event-converter](#event-converter) [event-history-processor](#event-history-processor) [ship-history-processor](#ship-history-processor) |
