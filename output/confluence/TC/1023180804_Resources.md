# Resources

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/1023180804  

## Content

This section contains **AI-powered tools, assistants, and GPTs** that support Teqplay workflows.  
Resources are reusable, reliable components that help teams **create content, analyze data, summarize information, and accelerate processes**.

**Resources** are AI assets designed to support specific Teqplay activities, such as:

* Writing and improving reports
* Drafting customer or stakeholder content
* Supporting benchmarking and BI workflows
* Assisting with research and analysis
* Providing reusable templates and patterns

Each Resource comes with:

* A **direct access link** to the GPT or tool
* A **dedicated page** describing how to use it
* Clear **use cases** and **instructions**
* Contacts for questions or improvements

## **How to Use Resources**

1. Open the **Resources Collection**
2. Select a Resource card
3. Visit the **Resource Page** for instructions
4. Open the associated GPT or tool
5. Use the provided prompts/templates
6. Validate the output and adapt it for your workflow

---

## **Contribute a New Resource**

If you’ve created or discovered an AI tool that others could benefit from:

1. Click **+ Add entry** on the **Resources Collection**
2. Enter the the Resource Name, Type, Access link and Contact
3. Type in the Resource Name on Resource Page field, click **+ Create page**
4. This will create a page using the Resources Page template. Click on the link to go to this new page. Refresh might be needed.
5. Fill in the details (overview, capabilities, usage, etc.)
