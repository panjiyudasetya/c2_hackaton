## 1. Use Case

AI supports writing benchmarking reports and Port Turnaround Time performance articles.

## 2. Purpose

Using the existing benchmarking reports and PTO dashboard visualizations with Port Benchmarking Analyst GPT, writing new low effort articles.

## 3. How It Works

Determine the scope for the article/report (port, type of cargo, time period)

As preparation, you might

* use Deep Search to get some context information on the port (external disturbances such as storms, fog events, port closures, strikes, …)
* brainstorm about the content and story structure

Take screenshots from the PTO dashboard, with visuals and tables that are relevant for the story.

You can also use Copilot with Power BI integration to summarize the data.

Ask GPT to create a first draft.

Give feedback to finetune.

## 4. Inputs & Outputs

* **Input:** Scope (port, type of cargo, time period), visuals and tables from the PTO dashboard
* **Output:** First draft for an article

## 5. Notes

It might require several iterations to reach the desirable state. Clearly indicate that the language should be similar to the benchmarking reports. Validate the data and context information provided by GPT.

It can be used in combination with Copilot with Power BI integration.
