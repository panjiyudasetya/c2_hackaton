# Maps Copyright

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/652705837  

## Content

1. Login to MapTiler
2. Select the map that you use in the application
3. When on the details page scroll down to the `Attribution` section. Here you see a copy button, this will copy the copyright text including the required links.
4. Open your Application
5. For leaflet you have rendered `<TileLayer .../>` here you should add the `attribution=''` with the content you just copied.
6. For Mapbox there's probably a simular thing for the attribution, ... Add this later
