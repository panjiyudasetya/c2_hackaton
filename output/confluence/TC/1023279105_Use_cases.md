# Use cases

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/1023279105  

## Content

This section captures **real examples of Generative AI applied to Teqplay workflows**.  
A **Use Case** is a documented scenario where AI improves a specific Teqplay process.

The goal of this page is to help you quickly:

* Discover proven AI workflows
* Understand how they work
* Explore domains already benefiting from AI
* Replicate or adapt these use cases for your team

Each use case describes:

* **What the AI supports** (e.g., benchmarking reports, meeting summaries)
* **Why it’s useful** (purpose)
* **How it works** (short workflow)
* **Inputs & outputs**
* **Important notes or limitations**

## **How to Use This Section**

1. Open the **Use Cases Collection**
2. Pick a use case relevant to your work
3. Read the **How It Works** section to adopt the workflow
4. Apply it step-by-step with your own inputs
5. Consult the **Resources** linked in the Use Case card
6. Reach out to the **Contact** for support or questions

---

## **Contribute a New Use Case**

If you discover a new AI workflow that adds value, please document it:

1. Click **+ Add entry** on the **Use cases Collection**
2. Enter the the Resource Name, Type, Access link and Contact
3. Type in the Use case Name on Use case Page field, click **+ Create page**
4. This will create a page using the Use Case Page template. Click on the link to go to this new page. Refresh might be needed.
5. Fill in the details (overview, capabilities, usage, etc.)
