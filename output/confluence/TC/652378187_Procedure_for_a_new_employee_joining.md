# Procedure for a new employee joining

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/652378187  

## Content

# Documents

* Employment Contract: signed
* Copy passport
* Copy Bank-card
* completed employee details form
* Completed taxform <https://download.belastingdienst.nl/belastingdienst/docs/model_opgaaf_gegevens_voor_de_loonheffingen_lh0082z4pl.pdf>

# Action

Register with Cijferkamer ([info@cijferkamer.nl](mailto:info@cijferkamer.nl)) \* Startdate \* salary \* number of working days \* include employee details form \* include taxform \* include copy passport \* include copy bank-card

For employees only (i.e. no interns // no 0-hours contracts)

* Register new employee in HumanNet / Felison [http://verzekeringsinzicht.nl](http://verzekeringsinzicht.nl/)

  + Create new employee
  + Registreren Nieuw Dienstverband (in profiel nieuwe medewerker)
* Register with ConceptPlus / <https://asp.tracksoftware.nl/conceptplus/portal.nsf/Portal?ReadForm>
