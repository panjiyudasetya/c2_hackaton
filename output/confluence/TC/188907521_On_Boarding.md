# Introduction

PortReporter, in a nutshell, it’s a web application that receives **Port**CallEvents from several specialized data sources (input) and **reports** users (output) about them upon automatic or customized event subscriptions.

In the process, Portcalls are built as a group of organized and categorized PortcallEvents by the same **PortCall Identifier** (made up by Teqplay upon vessel, port and timeframe in another software component).
