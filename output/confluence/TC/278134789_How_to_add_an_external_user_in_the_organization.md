# How to add an external user in the organization

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/278134789  

## Content

1. Go to [Users - Microsoft Azure](https://portal.azure.com/#view/Microsoft_AAD_UsersAndTenants/UserManagementMenuBlade/~/AllUsers)
2. Click New user> Invite external user

3. Type in the email address of the user to be added, click Review + invite. Click Invite.
