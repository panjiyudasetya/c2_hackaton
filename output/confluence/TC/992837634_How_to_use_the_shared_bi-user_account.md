# How to use the shared bi-user account

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/992837634  

## Content

[bi-user@teqplay.com](mailto:bi-user@teqplay.com) is an alias created for BI users at Teqplay who require a Power BI Premium license. This account is granted access to our Copilot capacity, and can be used for demo purposes.

Steps to use:

1. Click **Open this report** on the email you received (or alternatively, [this link](https://app.powerbi.com/Redirect?action=OpenLink&linkId=5dtoP6RsKC&ctid=2fe632ad-7ca8-4a17-bc1a-f9ac8f86b2d2&pbi_source=linkShare_m365Notify)), directing you to the report on a Copilot enabled environment. (At this point, only the PTO Ports dashboard is available in this environment. Others can be made available upon request.)

2. Sign in to [bi-user@teqplay.com](mailto:bi-user@teqplay.com)
3. Enter the code received in your mailbox
4. Start using Copilot with Power BI!
