# How to start using it

How to start using it

Currently we are using Microsoft Power Bi as a BI Tool

### Installing BI Tool:

For Windows:

* Go to Microsoft Store
* Search for “Power BI Desktop“
* Install it

### Installing OpenVPN

To connect to the database you will need to have a connection to our vpn.

How to connect is described here:   
[Open VPN](https://bitbucket.org/teqplay/teqplay-wiki/wiki/OpenVPN)

### Installing ODBC

Download the ODBC driver following the link: <https://www.postgresql.org/ftp/odbc/releases/REL-17_00_0002/>

Open the driver

In the System DNS tab,

Click Add

Select PostgreSQL Unicode(x64)

Type in a name for the Data Source, input Database, Server, User Name.

Test the connection. If it is successful, click Save.

### Using:

* Open Power BI Desktop
* Press “Get Data“
* Search for ODBC and press connect
* Select the ODBC Configuration file you have already installed and click OK

* Select the tables you wish to import and click Load
* Use the button to Select Related Tables if needed
* Now you are done

# How to make the data up to date

The current way to update the data is through an endpoint

* Get a token from <https://ptodev.teqplay.nl/>

  + by looking in the F12 menu in your browser
  + Go to the network tab
  + Select the call with all or any other call made to the backend
  + Copy over what is marked red in the picture
* Do a GET to {{url}}/datamart/generate   
  with url being the url of the backend, if you don’t know which url this is it can be found in the same way as the token/

  This takes a while till it is done.
