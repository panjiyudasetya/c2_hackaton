## 1 Introduction

RouteScout is an application that allows you to view, debug and edit graphs. To use RouteScout, you will need a Keycloak account that has access to the project. You can find the application on the following URL’s:  
  
**PRODUCTION:** <https://routescoutv2.teqplay.dev/>  
**DEVELOPMENT:** <https://routescoutv2dev.teqplay.dev/>

## 2 Application layout

The application layout has two versions, one for each of the modes.

### Route Planning

1. Navigation Menu
2. Primary Panel (routes, settings, config)
3. Details Panel (shows details of selected map elements)
4. Mode Switch
5. Toolbar
6. Toolbar Actions

### Graph Manager

1. Navigation Bar
2. Primary Panel (graph conflicts, entity issues, config)
3. Layers Panel (show/hide layers)
4. Details Panel (shows details of selected map elements)

6. Toolbar
7. Toolbar Actions

## 3 Features

### Graphs

The sources page allows you to view different graphs and their versions, generate new graphs, or sync them to production. Graphs can be marked active, but only one can be active at a time. You can remove a version of a graph by clicking on the three dots on the graphs list item, and selecting “Delete”. You can only delete graphs which are not marked as active.

#### Generation

Graphs can be generated by clicking on the “Generate” button at the index page of graphs. This will bring you to a screen where you can view the sources that will be used for generation. You can manually start the generation by clicking on “Start”. Once the generation is done, a message will be shown with some additional information.

#### Syncing

Syncing a graph works similarly to generating graphs. Clicking on the “Sync” button at the graphs index page will bring you to a screen where you will be given details on which graph will be synced to production. The latest active main graph will be used. You can then start the syncing process by clicking on the “Sync” button.

### Sources

The sources page allows you to view different sources for graphs, their latest used version, and whether they are used or not. If a source has an update, you can start the process to update the source by clicking on the “Update” button.

### Map

The functionality of the “Map” view is split up into two modes, Graph Manager & Route Planning. These modes are explained in detail in separate chapters, but there is some generic functionality between the two:

#### Viewport

The viewport of the map is in the center of the screen of the “Map” page. You can click, drag or scroll in this viewport to interact with the map. The viewport also contains some buttons in the top right, which allow you to delete map objects or reset the angle.

#### Maximum Dimensions

Debugging often requires viewing maximum dimensions of graph edges. To simplify this, click on the “Dimensions” button in the bottom left of the viewport. This will open a popover with color codes for each dimension. The edges on the map will be color-coded accordingly.

#### Config

The config tab in the primary panel is the same regardless of the mode you are in. In this tab you can configure the map style, projection, and global layer visibility.

## 4 Map - Route Planning

The route planning mode allows users to create routes to debug the most recently created main graph.

### Defining a route

To define a route, select the route tool in the toolbar. Define route points by clicking on the map. To change the points you placed, go into the select mode by clicking on the cursor in the toolbar, and click on a route node. When you have selected a route node you can move it by dragging it with your cursor, or delete it by pressing DELETE on your keyboard (or clicking on the trash bin icon on the top right of the map). If you want to start over, you can click on the “Clear” button in the toolbar.

### Configuring route settings

Settings for the route such as width, height, and length can be configured through the settings tab in the left panel. To apply the settings, the routes will need to be re-calculated.

### Viewing routes

When you have defined all route points, you can click on the “Calculate Routes” button in the toolbar, to get the route results. Clicking on a result in the list will show you details about the route such as the infrastructure that you will encounter. You can click on the infrastructure item to fly to it’s location on the map.

### Non-navigable routes

Some routes will be non-navigable based on your route settings. To debug these, enable the “Include non-navigable” option in the route settings and calculate the routes. Non-navigable routes will be shown in the list with a red icon. Non-navigable edges will be drawn in a red color on the map. You can now select edges to find out which properties are impacting the non-navigability.

## 5 Map - Graph Manager

The graph manager mode allows users to view various graphs, and draw objects to enhance or modify the graph. The drawing of objects can be initiated by clicking the appropriate tool in the toolbar at the bottom of the screen. Hovering over a tool will tell you it’s name.

### Area Filters

Area filters are used to exclude or include sources within a user-defined map area/polygon.

### Bounding Boxes

Bounding boxes are used to connect graphs or add infrastructure. A bounding box is a polygon which contains a “Bounding Point”. The bounding point is the location that will be used to connect edges that pass through it, and provide a location for the infrastructure that is added.

### Manual Graphs

Manual graphs are graphs that have been drawn by a user. These objects are hidden by default. To toggle their visibility, go to the layers panel in the top right, open the manual graphs folder, and click on the *eye* icon for the graph.

#### Drawing/Creating

To create a new manual graph, go into the manual graph mode by selecting the tool in the toolbar. To start drawing on an existing graph, select one of the graph’s edges. To create a new graph, click anywhere on the map.  
  
Graphs consist of edges, nodes, and junctions. The start and end of each edge is a junction, which is displayed as a blue dot. Each edge can contain multiple nodes, which are displayed as white dots. You can draw new edges or connecting existing ones by drawing on the map. Your mouse will snap to edges and junctions when you move close to them.

#### Editing/Moving/Deleting

To interact with the graph elements, select the secondary graph mode tool which is located in the toolbar (“Select & Move” tool). You can now select nodes, junctions and edges. You can move nodes/junctions by dragging them, or delete edges by selecting them and pressing “DELETE” on your keyboard.

### Conflicts

When generating a main graph, conflicts may arise. You can view these conflicts in the conflicts tab in the primary panel. Each conflict will contain a description and, if applicable, possible solutions or steps to resolve the conflict. You can manually mark the conflict as resolved once you have resolved it.

### Issues

Objects that are drawn on the map can have issues. These issues are displayed in the issues tab in the Primary Panel. Clicking on one of the issues will select the object and fly to the object location on the map.
