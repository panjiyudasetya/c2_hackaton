# Atlassian Rovo ChatGPT Connector

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/1080426497  

## Content

## 1. Integration Name

[Atlassian Rovo](https://chatgpt.com/apps/atlassian-rovo/connector_692de805e3ec8191834719067174a384) ChatGPT Connector

## 2. What It Does

Allow access from ChatGPT to Atlassian Jira and Confluence.

## 3. How It Works

From within ChatGPT you can indicate you want to link to Jira or Confluence by using in any text the “@atlassian rovo” tag after installing the connector and providing it access to your account in Confluence or Jira.

## 4. Where It’s Used

Officially it can be used to both retrieve information that is stored in Confluence and to extend the data in Confluence. Testing demonstrated that it is very useful for collecting data from Confluence into chatGPT. However, trying to enter information into Confluence in an existing page resulted in multiple limitations where ChatGPT was not allowed to update because of policies etc. In the end it showed how to ‘copy-paste’

## 5. Notes

Use for quick scanning confluence and summarizing is working properly, updating has its limitations. Basically, I did not manage to get it to update anything, in the end it told me to copy paste the content into Confluence myself.
