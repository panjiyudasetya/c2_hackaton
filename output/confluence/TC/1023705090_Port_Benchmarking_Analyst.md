# 1. Overview

This GPT is for creating new reports and articles for benchmarking and performance analysis.

**Who it is for:**  
Marketing and BI.

**Typical use cases:**

* Creating a new benchmarking report
* Making amendments/improvements in a report draft
* A new performance article for a port or terminal

# 2. Capabilities

**This GPT can:**

* Generate a first version for reports and articles
* Summarize reports and articles
* Brainstorm about potential content
* Deep search context in ports in a period in time (weather, strikes)

# 3. Instructions / How to Use

A step-by-step usage guide.

1. Open the [Port Benchmarking Analyst GPT](https://chatgpt.com/g/g-692f00eb2694819180b56e33e0e08b78-port-benchmarking-analyst)
2. Provide context (purpose, focus in topic and ports)
3. Add visuals
4. Review the output for accuracy
5. Give feedback on sections, inspect iterations
6. Copy to your working document
7. Validate domain correctness before publishing

# 4. Prompt Patterns / Templates

> *You are helping me write content for [audience].*

> *[paste bullets / input].*
