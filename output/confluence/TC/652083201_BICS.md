# BICS

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/652083201  

## Content

This page covers everything you need to know about BICS.

We are using BICS as a backend to support RiverGuide E-meldingen. In this way skippers can let the authorities know where they are going to travel and with what kind of cargo they are doing this.

`RiverGuide --> Platform <--> BICS <--> Authorities`

We have two Linux machines running to support this, which are running BICS applications on them.

BICS Live
BICS Acceptance

On acceptance we are running a specific demo/test version, live is running the regular version.

You can SSH into the servers by using the VPN and using the internal IP address.

To install the BICS software we have used a VNC connection. When the VNC server is running (which you can run by doing `vncserver` command in SSH) you can use a VNC client to login to the user. For example, 172.1.1.1:5901. The password can be found in Teqplay Vault.

# Using BICS

The BICS instance can be reached via the internal ip address when connected to the VPN. For example, the acceptance server currently can be reached by going to <http://bics-acceptance.teqplay/> Credentials to login are `bics2` and `bics2`.

In here you see all the travels that have been created by the skippers. Sometimes this dashboard can be used to debug some problems.
