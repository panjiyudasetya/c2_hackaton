# How to connect to the Gateway Machine

**Space:** TC  
**URL:** https://teqplaybv.atlassian.net/wiki/spaces/TC/pages/686424065  

## Content

1. Open Remote Desktop Connection (or an application equivalent)

2. Get the credentials from BitWarden:

* Collection: Live Systems/Data engineering
* Item name: PowerBI Gateway

3. Fill in the Computer and Username:

* For the field Computer, type in the Website (make sure that http:// is not copied from BitWarden when filling in the Remote Desktop Connection)
* For Username, type in the Username in BitWarden

4. Click connect.
5. Fill in the Password.

* This can be found again in BitWarden.

6. You are now connected to the Gateway machine.
