## 🚀 GitHub Copilot

**What it is:**  
GitHub Copilot is an AI pair programmer that helps you write code faster by suggesting lines or entire functions directly in your code editor.

**Installation:**  
Follow the official installation guides for your preferred editor here:  
👉 [GitHub Copilot – Supported Editors & Installation](https://docs.github.com/en/copilot/getting-started-with-github-copilot/getting-started-with-github-copilot-in-your-editor)

## ⚡ Augment Code

**What it is:**  
Augment Code is an AI assistant that integrates with your workflow to enhance both frontend and backend development, independent of your code editor.

**Installation:**  
Check out the official Augment Code installation documentation here:  
👉 [Augment Setup Guide](https://docs.augmentcode.com/installation/)
