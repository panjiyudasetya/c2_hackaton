### Copilot — 2026-02-04 on `src/main/kotlin/nl/teqplay/poma/feature/infrastructure/customerarea/AbstractCustomerAreaDatasource.kt`

Changing customerId from a unique index to a regular index is a significant data model change. This allows multiple customer areas to share the same customerId, which may be intentional but represents a breaking change in the data constraints.
