## Description

**_Add all-visits baseline (all_average_value / all_standard_deviation) to port performance analytics_**

Adds a second statistical baseline alongside the existing occurred-events-only average_value/standard_deviation on fact_port_performance_analytics, for all 6 metrics (Moored, Shifting, SteamingIn, SteamingOut, WaitDuringVisit, WaitBeforeArrival):

Schema: fact_port_performance_analytics gets two new NOT NULL columns, all_average_value / all_standard_deviation — averaged over every visit in the period (NULL durations coalesced to 0), vs. the existing columns which only average occurred events (duration > 0).
Temp tables: all 6 temp_port_performance_* scratch tables get the matching two columns.
Calculation: each calculate_<metric>.sql template now computes both baselines via a base_port_visits → all_visits_summary / filtered_visits_summary CTE chain, joined on port_unlocode.

  insert only worked at all because the columns didn't exist in any upstream

- `0b07c6be` **ryan_at_teqplay** (2026-09-01): fix(port-performance-analytics): backfill all_average/all_stddev on migration to avoid NotNullViolation

  table (psycopg2.errors.NotNullViolation: column "all_average_value" ...
  contains null values) - fact_port_performance_analytics already has rows in
  every environment this migration runs against. Add with DEFAULT 0 to backfill
