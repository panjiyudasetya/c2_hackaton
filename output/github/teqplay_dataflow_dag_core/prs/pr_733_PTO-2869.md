## Description

### Description

- **New KPI: `gold.kpi_bunkering_weekly`** — event-centric weekly bunkering metrics aggregated by port, vessel type, ship type, ISO calendar week, berth, and terminal. Follows the established KPI four-step pattern (DDL → register → task groups → DAG wire-in).
- **New Silver MV: `silver.enriched_bunkering_weekly`** — enriches each bunkering event at write time with ship category, berth context (`berth_id`, `berth_name`), terminal context (`terminal_id`, `terminal_name`), and port name. Resolves berth/terminal via `fact_berth_visit` → `dim_berth`, with a fallback to `fact_terminal_visit` → `dim_terminal` when no berth visit exists.
- **Grain**: `port_unlocode × vessel_type × ship_type × calendar_week × berth_id × terminal_id`. `berth_id` and `terminal_id` use `''` (empty string) as the NOT NULL sentinel for unlinked events, enabling roll-up queries at any level without NULL-key issues.
- **Metrics**: `total_bunkering_duration_hours`, `bunkering_event_count`, `vessels_served_count`, `avg_bunkering_duration_per_event`. All four are registered in `gold.kpi_metric_registry` (Layer 4) on every refresh.
- **Docs**: Added `README.md` with architecture diagrams and `CLAUDE.md` with commands, architecture overview, and coding standards.
