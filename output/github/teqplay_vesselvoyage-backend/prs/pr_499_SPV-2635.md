### michel-teqplay — 2025-05-15 on `src/main/kotlin/nl/teqplay/vesselvoyage/service/PostProcessingService.kt`

Not a big fan of the "check, sleep, retry" mechanism, it would be nicer if there was something you could block on? Something like a semaphore could be used here ... if you submit n jobs you could create a semaphore, initialized at zero. Every finished job would up the semaphore by one, and the wait function could try to down the semaphore by n, and this would block until every job is completed. But that is a bit more complex, not sure if it's worth it.
