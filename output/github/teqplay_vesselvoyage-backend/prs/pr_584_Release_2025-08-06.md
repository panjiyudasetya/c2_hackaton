## Pull Request Overview

This PR introduces a comprehensive story repair system to fix broken ship stories through recalculation. The system attempts to repair inconsistencies by recalculating with event history data and falls back to full recalculation if needed.

- Adds story repair service with configurable thread pool for processing repairs
- Implements automatic trace generation for ongoing visits without end times
- Introduces various optimization and code improvements across the codebase
