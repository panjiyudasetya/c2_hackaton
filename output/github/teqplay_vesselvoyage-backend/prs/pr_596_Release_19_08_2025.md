## Pull Request Overview

This PR modifies the vessel voyage API pagination system by transitioning from traditional page-based pagination to cursor-based pagination using `afterId`. The change also includes improvements to ship detail handling and API response structure.

Key changes:
- Replaces page-based pagination with cursor-based pagination using MongoDB's `_id` field
- Consolidates separate endpoints into a single combined endpoint
- Enhances ship detail logging and handling for null IMO values
