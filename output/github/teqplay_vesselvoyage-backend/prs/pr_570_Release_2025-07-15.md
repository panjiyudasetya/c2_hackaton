## Pull Request Overview

This PR introduces configurable activeness monitoring for event and AIS stream consumers, adds retry toggles for the recalculation service, refines null-safety in infra caching, adjusts logging levels, and updates Helm resource allocations.

- Added `activenessMonitoring` settings to both test and main `application.properties` and to the corresponding `Properties` classes.
- Implemented scheduled throughput checks in `EventsMessageHandler` and `AisStreamingMessageHandler` with a new `ProcessingRefreshEvent` to refresh consumers.
- Integrated a `reventsRetryEnabled` flag into `ReventsRecalculationService`, updated infra cache accessors for null-safety, lowered noisy log levels, and reduced memory requests in Helm charts.
