## Description

When searching in the frontend of example for {{Berth 24}} you find a lot of results because it also returns all berths that have a unique id containing {{24}}.

Adjust this so the fuzzy matching doesn’t do this anymore for identifiers. They should be replaced on direct matching instead. While still maintaining the fuzzy matching on for example the Name field.
