# [CC-102] Run a prediction again if a vessel moves significantly

**URL:** https://teqplaybv.atlassian.net/browse/CC-102  
**Type:** Subtask | **Status:** Done | **Priority:** Medium  
**Reporter:** Michel Wilson | **Assignee:** Michel Wilson  
**Created:** 2024-11-25 | **Updated:** 2025-02-07  
**Board:** CC board  
**Parent:** [CC-98] Connect ETA predictor to Routescout  

## Description

For every position update of a vessel, if there is an existing prediction, find the closest point on the predicted path. If the distance to the predicted point is above a certain threshold or if the predicted ETA at that point deviates significantly, schedule another prediction for this vessel.
