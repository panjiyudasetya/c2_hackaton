## Description

Looking into a case brought up by Fred: One Altair Steaming in 5.81 hr (attached screenshot from dashboard), [in timeline|https://timelinedev.teqplay.nl/431710000?URL=https%3A%2F%2Fapi.teqplay.nl%2Fv0&from=1697097600000&to=1697264137000&selectedTime=1697106865417]

!image-20240219-100132.png|width=719,height=455!



Seen this also in multiple other cases. It seems that in most of the ports the right order would be:


* Actual pilot on board
* Latest timestamp that we got based upon:
** Fallback based on pilot area
** Fallback based on Anchor area

I think for some ports this might lead to confusion i staying strict to a fallback order, so I would say it should be the latest timestamp we got.
