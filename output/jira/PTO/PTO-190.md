## Description

Had multiple situations where the vessel visited a target port (ESALG in the example) twice with 3 or more visits to other ports in the middle. We tried to address this situation using (r)events, but found out these (r)events are not guaranteed to be available.

Let’s fix this situation using vesselvoyage for now (and probably later this can be done even better using (r)events or so).
