### Wouter Naloop — 2024-02-20

Currently i added this feature on the report level. This means that it can be for all ports in the reports or no ports. 
We decided in the planningsmeeting that this is sufficient for now and if we bump our heads we will make this more specific

This can be used by providing 

{noformat}onlyRealTimeAis: true{noformat}

into the normal generation request of the port
By default this value is False.
