# [PTO-291] Make the PTO ETL code testable and stable

**URL:** https://teqplaybv.atlassian.net/browse/PTO-291

## Description

During generation of recent reports we found out that generating reports with a changing rule-set (assumed to be backward compatible) without proper safe guarding of previous assumptions does lead to unexpected changes and regression issues.

Let’s make sure we safeguard at “unit-testing” level the execution of those definitions.
