## Description

7ff9a911-4025-459e-8d12-b4c1f07ca737.VISIT shows an anchor time of one of the anchor waiting periods between berths. Anchoring should only show before the berth visit as anchoring, in between berth visits it should count as ‘waiting in between berths duration'.
