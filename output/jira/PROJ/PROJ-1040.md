Feature requests
Numerous users here are requesting the ability to turn off the pop-up window that shows when one hovers over a vessel. When trying to view the screen in congested areas, the windows will often cover other vessels. Desire is a check box with each fleet or even a profile setting that applies to all fleets that disables the pop up window.
If we were to reenable the pop up
Longer term feature - Changing the info in the pop up as the current info is marginally useful for our users. Name and speed are already available via the ship label. What you be more useful are different fields in the pop up such as speed, assigned berth, vessel type, linesman, Tug Co. Pilot No.
 Pop up doesn't "stick" like it does now. Currently it requires a very specific motion to get the pop up to go away. Preference is the pop up only shows while directly hovering over the vessel.
