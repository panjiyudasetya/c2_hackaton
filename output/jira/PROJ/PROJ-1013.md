### Joaquin Marquez Bugella — 2026-09-14

I have noticed data issues due to missing data from the USHOU movements and berth visit name mismatches.

If berth names were well matched, I believe the collected info would be accurate regarding pilot info.

On the other hand, the movements displayed in the dashboard (port view) aren’t really accurate, as the {{Underway (Pilot on)}} or {{Off time (Pilot off)}} display the movement start and end respectively, which has not necessarily to do with the {{pilotageState}} field.

I would say we’ve to evaluate the Port View dashboard state to display relevant pilot data, as well as review the visits matching mechanism (which needs the berth mapping to be properly done).
