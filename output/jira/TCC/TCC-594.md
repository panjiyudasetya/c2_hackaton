## Description

h2. Description

Main goals we want to achieve:

# Highlighting what is required.
## Might as well disable the create button when not all required fields are filled in.
# Notify the user what they need to fill in when missing anything.
# When an exception happens on the backend side don’t close the create/edit screen, to give the user a sense that they lost all their progress.
# Be consistent between all creation and edit forms (Port and Berth are handled differently).
# Have the create and cancel button available on both {{details}} and {{locations}} tabs.
# Have a reset button for each select box consistently instead of sometimes only showing it.

h2. Dependencies

ContextMapping team is using the tool quite extensively, keeping them in the loop is key here, so they know what will be changed, when it will be changed.

h2. Definition of Done

* Tested within the team
* Checking with ContextMapping team if they have feedbacks
* Deployed on Prod
