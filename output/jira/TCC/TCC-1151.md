## Comments

### Darius Wattimena — 2026-08-04

*Root cause analysis*

Scenario {{d3cb5569-8bda-49f2-b6d6-72d2bbd05f3b}} (SGSIN, window 2024-12-01 → 2026-08-26, prod):

* Started 2026-07-28 11:21 UTC. Replayed healthily for ~45.5 hours: *58.3M events persisted, cursor reached 2026-04-28T04:00 (~85% of the window)*. Last event persisted 2026-07-30 08:51:31 UTC.
* At that moment the *revents-engine container was OOMKilled* — confirmed via kube-state-metrics: {{kube_pod_container_status_last_terminated_reason{container="revents-engine", pod="revents-engine-job-0-q9rzn", reason="OOMKilled"}}}.
* Kubernetes restarted the container in place (Job {{restartPolicy: OnFailure}}); the fresh engine answered the next progress poll with {{id="initial"}}; the orchestrator marked the scenario {{CRASHED (REVENTS_ENGINE_INCORRECT_SCENARIO)}}, discarding all ~17 months of completed replay.
* Ruled out: orchestrator restart (pod stable, 0 restarts during the run) and node loss (no node rotation around the crash).

Why it looked like it "stopped itself": the OOM reason is recorded nowhere — the Job pod (holding the termination state) is deleted at teardown, and the scenario doc only stores the generic id-mismatch reason, with no timestamp or detail.

*Planned changes* (split over several PRs):

# Forensics & guardrails — persist crash detail + K8s exit reason (incl. OOMKilled) on the scenario, Slack alert on crash, stall watchdog, bounded phase retries, graceful shutdown; also fixes a separately-found bug where an orchestrator restart mid-run silently FINISHES a scenario with truncated data.
# Zero-loss orchestrator restarts — durable event queue + consumer re-attach.
# Resume-after-crash — persisted cursor + seeding open states from already-generated events + 1-day warm-up replay: a crash at month 17 costs ~2 days of re-replay instead of everything, with output identical to an uninterrupted run (the partial crash day is wiped and regenerated, so no duplicates).

Near-term mitigation for re-running SGSIN before this lands: raise the revents-engine container memory limit.
