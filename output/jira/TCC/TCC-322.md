## Description

h2. Description

Frontend fix here[https://teqplaybv.atlassian.net/browse/TCC-292|https://teqplaybv.atlassian.net/browse/TCC-292|smart-link].

When adjusting a main port we should not accept a blank string and validate if the port exists.

h2. Scope

Checking should be done on all endpoint where you can currently provide an unlocode. This check should be done on the controller level.

h2. Dependencies

Poma frontend should be the only one effect, given that nobody else uses the port creating/updating endpoints.

* [ ] Changes are tested

* [ ] (if applicable) Data env is correctly configured
* [ ] Plan of release communicated with consumers
* [ ] Consumer informed when changes are released
