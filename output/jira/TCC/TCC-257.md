**Parent:** [TCC-250] CSI Agentic AI for enhancing ship data  

## Description

Adjust ticket creating endpoint, source of the ticket needs to be set to something like {{Agentic AI}} so we can identify.

Needs to be manual checked before accepting the ticket.

Eventually after 100 test case ships we will make it so we automatically accept the tickets.

----

All new tickets from agentic ai will have their source set to {{AGENTIC_AI}} and tickets are automatically applied.

Also create an endpoint to Create and Complete Tickets by IMO
