# [TCC-277] VesselVoyage completeness testing

**URL:** https://teqplaybv.atlassian.net/browse/TCC-277  
**Type:** Story | **Status:** Done | **Priority:** Medium  
**Reporter:** Darius Wattimena | **Assignee:** Joost Dambrink

**Board:** TCC board  
**Parent:** [TCC-252] VesselVoyage visit completeness and correctness are guaranteed  

## Description

For completeness testing in VesselVoyage we want to ensure that the following categories are checked:

# Visit start/end
# PortAreas start/end
# Pilot inbound or fallback
# Pilot outbound or fallback
# Tugs

Set up new backend that subscribes to the VesselVoyage Visit and PTO SOF. Check in this new backend if the data above is existing. We just want to that the timestamps are there, not the location or if we have a Poma ID.

Save the result of the completeness check to the database, also expose the numbers to Prometheus so we can eventually expose them in a Grafana dashboard and set up alerts.

When testing make a Grafana dashboard, with this Prometheus metric and compare by hand if the number that you see is in line with the amount of incomplete visits that you have.

Re-use the VesselVoyage database server, to save the tested data.
