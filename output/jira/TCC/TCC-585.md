# [TCC-585] Fix an issue where the MarineTraffic link in CSI doesn't work anymore

**URL:** https://teqplaybv.atlassian.net/browse/TCC-585

## Description

h2. Impact

The MarineTraffic link in CSI is broken. This issue has persisted for several months. Users experience delays when processing tickets, adding approximately 10 seconds per ticket, which accumulates to about an hour a week.



Seems like the backend call we make to CSI is broken. The URL it scraped in the past exposed. Now it seem to be this URL, Example is for an MMSI search

{noformat}https://www.marinetraffic.com/en/global_search/search?term=525119198&types=7{noformat}

Lets do some research on if we can fix this in the frontend using a different approach or if we can do so by adjusting the backend somehow? So far backend option doesn’t seem to be feasible given they fully blocked direct API calls.



If we can’t fix the issue, then lets check with context mapping other tools they could use instead of marine traffic.

Potential mid-way solution could be having button that copies identifiers to clipboard in 1 go.

h2. Expected behaviour

The feature should open a link to MarineTraffic for the ship associated with the ticket.

h2. Steps to reproduce

* Open a CSI ticket.
* Click on the MarineTraffic link.
* Observe that the link does not work.
