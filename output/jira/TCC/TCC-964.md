# [TCC-964] Fix an issue on the public Timeline where it doesn't show AIS data ships that use multiple MMSIs

## Description

h2. Description

Yaren reported an issue that the public Timeline currently shows no AIS for certain ships in certain times.

It turns out to be related to a ship history call being done to get the trace which uses the current MMSI of a ship. However, this is wrong when the ship used multiple MMSI's throughout its journey, so it instead should use a IMO based ship history endpoint instead, as the IMO/MMSI mapping should be applied.

h2. Definition of Done

* Changes are tested
* Ship history IMO call is done when URL is IMO based
* Ship history throughout multiple MMSI’s is being shown for a single IMO
* Changes are released (on dev, live)
