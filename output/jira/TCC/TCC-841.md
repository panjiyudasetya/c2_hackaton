## Description

h2. Description

Grafana prometheus metrics all get skewed because they still use the old CSI client which has broken RestTemplate calls which didn’t use correct uri params.

This resulted in lots of call have the IMO number or MMSi directly into the tag of the metrics. Showing something like {{/ship/123456789}} instead of {{/ship/{mmsi}}}. Michel fixed this in the client on version {{...}}. All core components should be updated so they have this version or a later one so the metrics in Grafana make sense again.

Go through all projects and update CSI client if not already updated.
