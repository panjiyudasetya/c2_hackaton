## Description

h2. Description

Right now the completeness of a SOF is at ~50% this is wrong because we are way to strict for what we decided last week when we see a SOF as “complete“.

The following changes should be made:

{quote}* Pilot Inbound encounter (or Pilot area ATD) (above 125 length) or port has no pilot area
* Pilot Outbound encounter (or Pilot area ATA) (above 125 length) or port has no pilot area
* Tug (above 125 length)
* port ata & atd
* eos ata & atd
* stop, defining a visit{quote}

h2. Scope

No backfilling is needed because we will only need the last 2 weeks for the Obeya metric to show, no need to do this for historical data.
