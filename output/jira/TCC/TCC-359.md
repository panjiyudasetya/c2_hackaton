## Description

h2. Description

Add a new collection in the database, and models attached to that where we track the following timestamps:

* Request comes in into Revents API
* Load scenario interest (resolving ships/areas)
* Job creation
** Loading of AIS data
* Start monitoring
** Each monitor, start and end time
* Finished monitoring
* Finished post processing

h2. Scope

Only done inside Revents itself and saved, NOT exposing anything yet in the Revents API.
