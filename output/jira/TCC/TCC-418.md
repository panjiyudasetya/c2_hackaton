## Description

h2. Description

Create an endpoint which does the following:

# Ignore the field {{Draught}} if it is provided.
# Use the following logic for each field provided:
## If field is not set for the provided ship, directly apply ticket
## If field is different from what we know, then a ticket should be created for said field
## If beam or length is changed, only apply a change directly if 25 cm or less smaller then known value.
### 180 → 179.75 is fine
### 180 → 180.25 is NOT fine, ticket is expected to be created.

That said, most likely it is easiest to do the following:

# Create a ticket first all fields we can apply directly.
# Then create a ticket for all left over fields that need a review from the Context Mapping team.

h2. Dependencies

The Context Mapping is waiting for this to be here until we can start running the process for all ships.

How to test:

Test the behavior of the {{/v1/tickets/agentic-ai/create}} [https://csibackend-internal.dev.teqplay.com/swagger-ui/index.html#/tickets-controller/createAgenticAITicket|https://csibackend-internal.dev.teqplay.com/swagger-ui/index.html#/tickets-controller/createAgenticAITicket|smart-link] 
- the endpoint is only callable with the role: ROLE_AGENTIC_AI, otherwise it will result in a 401 unauthorized 
- the endpoint has a flag onlyApplyNonFilled default value = false, if true only values that are currently null will be changed and will not create a ticket
- normally it will apply changes for values that are currently null and create a ticket for changes that already have a value
- expect for beam and length they will be auto applied if they are reduced by a value less then 0.25( this is configurable but is currently set to 0.25 for both) as example:
150.00 → 149.75 auto applied
150.00 → 149.74 ticket
150.00 → 150.01 ticket
150.00 → 150.00 ignored
- every change with Draught (Max draught and Alternate draught) is ignored
- every change that sets a existing value to null is also ignored
- every change that changes a value to the current value is also ignored

a good example ship is HEIN imo: 7911856 [https://csidev.teqplay.nl/ship/961eb70c-931d-4f57-bf29-77aa8050db32|https://csidev.teqplay.nl/ship/961eb70c-931d-4f57-bf29-77aa8050db32|smart-link]
