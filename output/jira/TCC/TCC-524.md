# [TCC-524] Fix issue where ETA update doesn't publish SOF changes to PortCallOne

**URL:** https://teqplaybv.atlassian.net/browse/TCC-524  
**Type:** Bug | **Status:** Done | **Priority:** Medium  
**Reporter:** Darius Wattimena | **Assignee:** Joost Dambrink  
**Created:** 2025-11-06 | **Updated:** 2025-11-10  
**Board:** TCC board  
**Parent:** [TCC-152] Production Issues  

## Description

When we update the ETA in a visit or voyage it is expected that those changes are communicated as so.

While this is the case (I hope) for the ApiVisit and ApiVoyage to be updated when we adjust those, it is not when we make a update on the side of the {{NewESoF}} model, which should also result in an updated visit or voyage.

Next to this, when we update the {{NewESoF}} for a Visit it should also result in an updated SOF for both PTO and PortReporter as those can change as well.

h2. Dependency

It has a direct impact right now on PortCallOne. They only receive updated data once we any other fields it seems.
