## Description

h2. Description

AisStream currently publishes diff and history messages. They are eventually read using the AIS consume library which is a public library in the AisEngine project.

This library only works for NATS streams. Because we move to RabbitMQ it means we should have a library available which supports consuming messages from the new Diff and History queues.
