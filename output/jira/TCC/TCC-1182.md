## Description

Description
Besides this we would like to adjust the status we have in VesselVoyage scenarios to actually reflect what it is doing. Now for example we mark something as done even though it is still doing something.


I would say we should have the following statuses:
Queued
Progressing (Should be renamed to Running Revents)
Merging back
Post Processing
Finished which has 3 outcomes:
Finished
Partially Failed
Stopped
We currently show a progress bar only for how far Revents is, extending this progress bar to also take into account all the merging back and post processing tasks. Not only the Revents job.
