# [TCC-467] ETA predictor: Update LocationRequestUpdater to consider all scopes

**URL:** https://teqplaybv.atlassian.net/browse/TCC-467  
**Type:** Task | **Status:** To Do | **Priority:** Medium  
**Reporter:** Michel Wilson | **Assignee:** Unassigned  
**Created:** 2025-10-02 | **Updated:** 2025-10-02  
**Board:** TCC board  

## Description

The ETA predictor updates the start point of the travel prediction request segments in the true destination scope whenever a ship moves significantly, and then a new prediction is made. However, this is currently only done for prediction requests in the true destination scope. This code needs to be updated to consider the initial travel segments of the prediction requests in all scopes.
