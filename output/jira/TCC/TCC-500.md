## Description

h2. Description

* {{tomcat-embed-core}} version 10.1.40 is vulnerable to a DoS attack. Update the dependency which transitively pulls in this package, to ensure we use 10.1.41 or higher.
* {{netty-codec-http2}} version 4.1.119.Final is vulnerable to two DoS attacks and a request smuggling attack. Update the dependency which transitively pulls in this package, to ensure we use either 4.1.125.Final or 4.2.5.Final or higher.

They should be fixed on both AisEngine and API as they are both publicly available.
