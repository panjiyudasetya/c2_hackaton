# [TCC-1018] Adjust VesselVoyage PTO SOF to indicate in encounters which ship is a service vessel

**URL:** https://teqplaybv.atlassian.net/browse/TCC-1018  
**Type:** Story | **Status:** Done | **Priority:** High  
**Reporter:** Darius Wattimena | **Assignee:** Michel Wilson  
**Created:** 2026-06-17 | **Updated:** 2026-07-08  
**Board:** TCC board  
**Parent:** [TCC-896] Improved bunker capabilities  

## Description

h2. Description

Currently we have in {{encounters}} a {{type}} field which indicates the encounter type. Next to this in {{encounters.ship.type}} we also do this. This field isn’t very useful and being able to know if the ship is a service vessel would be much more valuable.

Having a way to indicate if the ship we current have the SOF of if it is a service vessel or not would be key for PTO to identify how they need to ingest the encounters.

Put the indication on the higher level {{ship}} field. {{ship.role}} can be null when not a service vessel. When a service vessel this will be filled in.
