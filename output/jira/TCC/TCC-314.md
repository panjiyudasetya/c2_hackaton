## Description

h2. Description

Plan in a meeting so we can see what is still needed to get rid of Poma V1 frontend.

## Comments

### David Hansson — 2025-08-18

h1. Feedback list:

*Kevin*:

* ✅  When creating a berth, you need to start from a corner, then manually connect the polygons. I prefer it automatically creating a rectangle like POMA V1, then we can easily adjust the length and width of the rectangle. In most cases that’s good enough.
* ✅ If you accidentally press the ‘create area’ button besides the delete button, it will overwrite the existing berth. It should only be allowed if there’s no area mapped yet.
Though I should get used to it, it would’ve been nice to have a small textbox whenever you hover over a button describing what it is.
* ✅ When I was connecting the polygons, for some reason I couldn’t get my mouse to move beyond a certain point even though I want the edge of the berth to be further. So I needed to create the berth as is, then edit it again.
* ✅ Can’t delete nodes if I accidentally made too many when mapping, which is quite a common occurrence.
* ✅ There is no ‘Select all’ option for ‘Vessel Type Allowed’ when creating berths. Since most berths will allow all types of vessels, the option was very helpful.
* ✅ Authority ID’ shouldn’t be a required field as we usually don’t know it when doing the berth mapping.
* ✅ After creating a new terminal, then adding a berth using the “+” button on the upper right corner of the box, the berth doesn’t automatically connect to that terminal.
The Box expands to the right, instead of wrapping down. This is fine when using a big monitor, but when working at home with a smaller screen size, it would cover half of the screen.
* ✅  Bring back the feature to paste a coordinate from Timeline and it will go to it
* ✅  I don’t see a way to map sub-ports in V2. This is still commonly used in V1, so it would also need to be in V2.
* ✅  It’s hard to get a perfect rectangle when mapping it in V2, it’d be nice to have a default rectangle and we can adjust the length and width.
* ✅  Sort the terminal and berth list, give option to sort based on name (A-Z), or by cargo category
* :red_square: I actually like mapping terminals more in *V2* as they often have irregular mappings, but having an option for a default shape can still be nice at times
* :red_square: Anchor areas especially can be very large and we often don’t know the exact location. Having a big square already pre-made would be very nice, Same as anchorages, pilot boarding places often cover a very wide area of all pilot activity that we could find. A big circle default shape would be very nice.
* ✅  It would be nice when after clicking the single location, it would automatically redirect you to the area mapping, like in V1. Just less clicks to do.
* ✅ In the new map service provider, the roof of buildings, silos, and tankers have a black box/circle, which I personally don’t like. I would prefer to see the actual buildings in Poma instead of having to do it in Google Maps. If there’s a way to turn it off as a setting, I’d very much like that please.


*Astri*:
* ✅ Add berth ( button) inside of terminal tab is working, but it doesn't link the newly created berth to the terminal selected automatically.
* ✅ Merged button & location feature are unavailable
* ✅ When creating/editing an area, I find it difficult to delete dots if I make a mistake:
 In the old POMA, it’s easier since we have “delete button” when we click one of the dots:
* ✅ I can't see the berth's length and width when I create the berth area in POMAv2data. This feature is available in old POMA and help me to check whether I create a suitable berth size.
* ✅ The 'Create' button when creating berth area only works when the "Authority ID" field is filled in, which we usually leave blank, as we don't have the information.
* ✅ When selecting 'Vessel Type Allowed', there is no 'Select All' option or the feature to choose multiple options at once. I have to reopen the dropdown menu and select each option one by one
* :red_square:  Happy that the width and length of the berth are now visible. However, for berths located in the corner, the polygon feature is missing. Previously, we're able to convert the rectangle into a polygon
