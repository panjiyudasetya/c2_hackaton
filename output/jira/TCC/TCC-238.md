## Description

Right now we have a set up of Poma and CSI as an example that should be “highly available“. However, as it turns out this set up has quite some flaws, as putting very high load on those applications results in them crashing, making the {{/actuator/health}} unavailable, meaning Kubernetes will shut down the pod.

This is not really what we want as besides the downtime it also makes the applications not reliable at all.
