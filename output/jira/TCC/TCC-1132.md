# [TCC-1132] Bump react-router-dom to 6.30.4 in timeline-public and csi (open redirect / XSS)

## Description

h2. Description

Dependabot flags an open redirect / XSS cluster in the react-router v6 stack. Bumping the one direct dep {{react-router-dom}} to {{>= 6.30.4}} pulls the fixed {{react-router}} and {{@remix-run/router}} with it and closes all three at once:

* GHSA-2w69-qvjg-hvjx, {{@remix-run/router}}, high, fixed in {{1.23.2}}
* GHSA-2j2x-hqr9-3h42, {{react-router}}, medium, fixed in {{6.30.4}}
* GHSA-9jcx-v3wj-wh4m, {{react-router}}, medium, fixed in {{6.30.2}}

Affected (both ship {{react-router-dom}} in the bundle):

* timeline-public on {{react-router-dom@6.22.3}} (alerts #42, #76, #41)
* csi on {{react-router-dom@6.14.2}} (alerts #30, #65, #29)

These sit in the router that actually ships to users. The risk is biggest on timeline-public since it uses the OIDC redirect flow ({{react-oidc-context}}), where a user controlled path could reach a redirect. On csi the navigation is all hardcoded internal routes so the practical risk is lower, but it is still shipped code and a high advisory in the tree.

h2. How to fix

* Bump {{react-router-dom}} to {{>= 6.30.4}} in both apps (stays within v6, no v7 migration) and reinstall so {{react-router@6.30.4}} and {{@remix-run/router@1.23.2}} resolve.
* csi jumps from {{6.14.2}} to {{6.30.x}}, so have a look at the v6 changelog for anything behavioural, though the API is stable across the v6 minors.
* Retest routing and the OIDC login redirect on dev, timeline-public especially.

h2. Definition of Done

* -{{react-router-dom}} bumped to {{>= 6.30.4}} in timeline-public and csi-
* -{{react-router}} 6.30.4 / {{@remix-run/router}} 1.23.2 resolved in the lockfile-
* Routing + OIDC redirect flow retested on dev
* Changes released on dev and prod
* Dependabot alerts closed (timeline-public #42/#76/#41, csi #30/#65/#29)
