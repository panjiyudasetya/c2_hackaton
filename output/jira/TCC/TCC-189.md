# [TCC-189] Fix an issue in the BerthMonitor where we don't fire UniqueBerthEvent consistently

## Description

Sometimes we don’t fire any end events. State gets stuck because the ship is still “inside“ the berth visit state.

Improve this mechanism to have a fallback in place where we periodically check if the ship is still inside the berth, otherwise trigger an end event.

Because they ships stay inside the berth visit it also has the side effect that it will never enter a different berth. Meaning we will lose a lot of unique confirmed berth events.
