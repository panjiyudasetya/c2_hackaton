# [TCC-237] Scheduling of new revents scenarios can get stuck when crashing when determining vessels

**URL:** https://teqplaybv.atlassian.net/browse/TCC-237  
**Type:** Bug | **Status:** To Do | **Priority:** Medium  
**Reporter:** Darius Wattimena | **Assignee:** Unassigned  
**Created:** 2025-06-18 | **Updated:** 2025-07-31  
**Board:** TCC board  
**Parent:** [TCC-152] Production Issues  

## Description

When this issue occurs the same scenario is being resolved and we end up with no new scenarios being spinned up, meaning this will stop all other scenarios from ever getting passed the queued step.

When a scenario is crashing, put it at the end of the queue instead of keeping it in the front.

----

DoD:

* Revents scenarios get spinned up even when a scenario before that is stuck.
* Determining vessels in a scenarios should never result in a crash.
