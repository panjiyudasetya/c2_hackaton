# [TCC-112] Have the possibility to run the automatic tests daily

**URL:** https://teqplaybv.atlassian.net/browse/TCC-112

**Parent:** [TCC-101] VesselVoyage accuracy testing  

## Description

Set up a CRON job in VesselVoyage that runs the comparing logic every day, to see if the “correct“ timestamps are still within the expected range.

Give a report on Slack with the result of said CRON job. (VesselVoyage has already things in place for this).

Information we want to share in Slack:

* Total amount of Visits (SOFs) that we checked.
* Accuracy of all timestamps (between 0% and 100%)
All categories of timestamps that are correct are a 1 and all that are wrong are a 0, then a average is taken from that (sum all 1’s and divide by total amount of categories). Example of this can be found here → [https://docs.google.com/spreadsheets/d/1pkvPsI5dWVkdGrBLIy_aKGtbqWz_-NE0exwJwif4YFk/edit?gid=1406128791#gid=1406128791|https://docs.google.com/spreadsheets/d/1pkvPsI5dWVkdGrBLIy_aKGtbqWz_-NE0exwJwif4YFk/edit?gid=1406128791#gid=1406128791|smart-link] where we have a result percentage of 92% for all the ships being checked.
* (if not too overwhelming) Summary of all visits that have a failed timestamp + some information what timestamps that are going wrong.
