# [TCC-1213] Create a new encounter api endpoint in VesselVoyage to expose all encounters of a type

## Description

Description
The PTO team currently has a milestone to ingest the full worldwide ingestion of bunker encounters.
For this the current VesselVoyage encounter API would fit will, however now it exposes only bunker encounters per ship. They want to have an endpoint which they provide a start and end time, and get back all bunker encounters of all ships worldwide.
Proposed endpoint:
GET /v2/encounter/list?start={time}&end={time}
This will return the same encounter models, but only the ones in the given time range.
The time range matching is done similar as we currently do for other time window based endpoints.
This might need a mongo index on the start.time and end.time of an encounter?
