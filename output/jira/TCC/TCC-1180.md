# [TCC-1180] Improve VesselVoyage scenario merging performance

**URL:** https://teqplaybv.atlassian.net/browse/TCC-1180  
**Type:** Story | **Status:** Testing Internally | **Priority:** Medium  
**Reporter:** Darius Wattimena | **Assignee:** Joost Dambrink  
**Created:** 2026-08-11 | **Updated:** 2026-09-14  
**Parent:** [TCC-1181] Recalculation process under control  

## Description

Description
Currently when merging back, we do this only for 1 ship for 1 scenario at the time.
We should make it possible to do this in parallel because we believe this would speed up merging back significantly.
Multiple scenarios should be able to be merge back at the same time, so we don’t block everything on a very big scenario.
We currently think it would be nice to use a threadpool using low prio threads. This way we can still keep priority on the real-time processing, while also merging back faster.
