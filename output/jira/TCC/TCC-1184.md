## Description

h2. Description

When you open a scenario details page you can do some actions.

Add the action to stop a scenario. In the revents API we can all {{/scenario/{id}/cancel}} as a PUT. We need to do the following to the VesselVoyage processing backend:

* Add a new recalculation endpoint to stop a recalculation
* Call the revents backend url (we should have a Revents client in place to do this?)

In the frontend we should make it so when you click the button it first provides a warning in the screen like we do for others, asking the user for a confirmation

Should only be able to cancel when running revents is still active. Not during merge or post-processing.

h2. Definition of Done

* Ability to stop revents scenarios
* Released on PROD and DATA (front-end/back-end)
* ContextMapping and PTO team are informed of this new button
