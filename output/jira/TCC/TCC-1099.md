## Description

h2. Description

Ships reuse MMSIs, we sometimes have the case that a tug uses an MMSI of a ship that in the past wasn’t a tug.

Encounter monitor should have a historic CSI role support? Now we just take “all current roles“.

Include time windows from IMO/MMSI mapping in role mapping in encounter monitor. This should be the active role mapping, so we know when processing in revents if the mmsi should result in an encounter, or if they could be ignored.

Make scenario testing like we already do for the encounter monitor, but include this new “role mapping“.
