## Description

h2. Description

As the first step for UAB we want to provide them with a temporary solution for their vessel location finding API.

This will require some attention given they want to have the following fields:

# MMSI
# IMO (if available)
# ENI (if available)
# Ship Name
# Location (Lat + Lon)
# AIS Destination
# AIS ETA
# Update time

We should have everything available except for the ENI in ship history. Making a temporary endpoints in the External API would be sufficient given that they will eventually start using our normal ship history endpoints.

*For now we do NOT want to extend ShipHistory with ENI support, but tackel this later.*

CSI should already have most of the information needed with all the ENI’s of known barges.

We don’t know yet in full detail if it is possible to request AIS only with a ENI, because if so then it makes querying hard without going first to CSI to resolve the MMSI.

# Authentication will be based on a secret (having that configurable via properties/configmap).
# Based on the request/response examples it seems like it also supports batch support.

h2. Dependencies
