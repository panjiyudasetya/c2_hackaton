# [TCC-548] Update API models to include the new ship identifier

**URL:** https://teqplaybv.atlassian.net/browse/TCC-548  
**Type:** Sub-task | **Status:** Done | **Priority:** High  
**Reporter:** Darius Wattimena | **Assignee:** Darius Wattimena  
**Created:** 2025-11-24 | **Updated:** 2026-01-20  
**Board:** TCC board  
**Parent:** [TCC-546] Add support for non-sea vessels to be processed in VesselVoyage  

## Description

Currently we expose the IMO on ApiVisit, ApiVoyage and all SOF models.

Good to implement this in a similar way how we handle event objects with a ship reference in AisEngine (ShipIdentifier).

This also means we have to make this IMO field nullable eventually, which might have big impact on our consumers.

DoD:

* New models and client are published
* Consumers are informed of changed models (Project team and PTO team)
* Deploy model changes to production
