## Description

h2. Description

Right now all the {{_id}} fields and in port the {{unlocode}} field can be nullable. This should not be the case as they are always filled in the database, meaning we can make them non-null without any issue.

h2. Scope

* What is part of this change?
* What is not part of this change?

h2. Dependencies

Might have effect on the Poma frontend which expects the models to be null?

External people will have no effect on this as they should be handling nullability right now, which should be redundant.
