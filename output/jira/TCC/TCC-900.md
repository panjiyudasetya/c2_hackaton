## Description

h2. 1.1 Stable Bunker Event Detection

*Description*
Detect bunker events in a _robust and stable way_, minimizing interruptions caused by AIS jitter.

*Requirement*

* Events should not “break” due to AIS jittering

*Value*

* Reliable foundation for all downstream features
* Prevents false positives / fragmented events

----

Look into bunker encounters to see how flacky/unstable they are, and start improving based on the found examples.

Look into the encounter monitor, tune the endurance of encounters, to fit better / more cases. Currently we now have a 3 minute quarantine time until we start/end the encounter.

Scope is to focus bunker encounters.

* -5 cases identified and fixed with improvements-
* -Changes are tested-
