## Description

Description
We currently decide if a ship is a sea vessel based on if it has an IMO.
We can use this logic to backfill for all ships:
When it has a IMO, set the field to true
Otherwise set it to false
This can be done directly in the database as a script, not making any logic changes in the code.
Definition of Done
Script ran in database DEV, PROD and DATA
