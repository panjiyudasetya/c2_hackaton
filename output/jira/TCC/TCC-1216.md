## Description

h2. Description

Hi Core component team, since some time in demos I do see ships spinning around on the map randomly. I did have a bit closer look now (in preparation for my chat with Kpler) and found out that we do get a trueHeading: 511 message. This triggers the front-end to use the courseOverGround for the direction of the vessel.

In the past we did have a 'calculatedHeading' field, generated on the fly for every vessel. Either there, or in the ingestion we then ignored the 511 in the trueHeading and kept the old trueHeading value instead. Would a solution like that also be an option?

Could it be this behaviour also has an effect on the encounter detections which need perpendicularity (like bunkers?)
