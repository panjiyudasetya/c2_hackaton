# [TCC-154] Fix issue where ship-history-processer goes OOM when starting up

**URL:** https://teqplaybv.atlassian.net/browse/TCC-154

**Board:** TCC board

## Description

The buffer collection is read in memory by a {{toList()}} call, then converted to an iterator, and then read via the iterator. This makes it go OOM. Convert this to not use {{toList()}} anymore. The big issue here is that we have a database cursor which needs to be closed, which is not supported by {{Iterator}}. Investigate if {{Flux}} can be used throughout, that might be a closable interface?
