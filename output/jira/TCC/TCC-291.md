# [TCC-291] Poma completeness testing

**URL:** https://teqplaybv.atlassian.net/browse/TCC-291  
**Type:** Story | **Status:** Done | **Priority:** Medium  
**Reporter:** Darius Wattimena | **Assignee:** Jamie de Leest

**Board:** TCC board  
**Parent:** [TCC-445] Context Mapping completeness testing  

## Description

Create an application that receives the information from the Poma API, make it so the application can be used later for other core services completeness checking as well.

We want to check the completeness of the following Poma models:

* Ports
** Anchorage
** PBP
** EOS
** name
** unique unlocode
** Terminals
** Area (inner & outer)
* Terminals
** Name
** id
** cargo type
** Berths
** Area
** Mapped to port
* Berths
** Name
** id
** cargo type
** type (quay, jetty, ect)*(Only for PTO port ports)
** Area
** Mapped to port
** Vessel type * (is it mandatory?)



Check daily if all ports, terminals and berths are complete.

Save result of this in the core-service shared database server, (the result will be in a separate database) and publish statistics of the result in Prometheus.

* Total ports complete
* Total ports not complete
* Total terminals complete
* Total terminals not complete
* Total berths complete
* Total berths not complete

Create a new dashboard to be used for all context mapping completeness, displaying the result that we pushed to Prometheus.
