## Description

Add a management endpoint that triggers the creation of prediction requests for all ships that have a resolvable true destination.

* get current ship state from ship history
* filter out ships for which we already have a prediction request
* in batches, submit the mmsi + ais destination to portmatcher, and for every ship for which the true destination is resolved, create a prediction request similar to how a true destination changed event is handled
