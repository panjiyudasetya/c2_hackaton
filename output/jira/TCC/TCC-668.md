## Description

h3. 1️⃣ {{RecalculationResult.kt}}

* All recalculation result models now use {{shipId}} *(String)* instead of *IMO (Int)*.
* This applies to:
** Single ship recalculation {{RecalculationShipResult}}
** Batch ship recalculation {{RecalculationShipsResult}}
** Merge-only recalculation results {{RecalculationMergeResult.ScenarioShip}}

Should be changed for all endpoints (if applicable)

{noformat}/v2/recalculate{noformat}

[*GitHub diff*|https://github.com/teqplay/vesselvoyage-backend/blob/db255cd4a85141ff918cbd8370d031210458774d/api/src/main/kotlin/nl/teqplay/vesselvoyage/model/RecalculationResult.kt ]

2️⃣ {{ReventsRecalculationStatus.kt}}

h4. Guarantees

* *Removed:* {{Guarantee.V1}}
* *Remaining:* {{Guarantee.V2}} only

This is used in some of the endpoints as parameter in /v2/recalculate but should not be used anymore (V1)

[*GitHub diff*|https://github.com/teqplay/vesselvoyage-backend/blob/db255cd4a85141ff918cbd8370d031210458774d/api/src/main/kotlin/nl/teqplay/vesselvoyage/model/ReventsRecalculationStatus.kt]

h2. 3️⃣ {{ProcessingRecalculateV2Controller.kt}}

All endpoints have changed from using IMO to ShipId (string)

h4. Get recalculations for a ship

{noformat}GET /processing/recalculate/v2/ship/{shipId}{noformat}

* *Before:* {{/ship/{imo}}}
* *After:* {{/ship/{shipId}}}

h4. Recalculate single ship

{noformat}POST /processing/recalculate/v2/ship/{shipId}{noformat}

* Path variable changed from {{imo}} → {{shipId}}
* Request params unchanged ({{start}}, {{end}}, {{guarantee}}, {{includeHistoricData}})

h4. Recalculate batch

{noformat}POST /processing/recalculate/v2/ship/batch{noformat}

* *Before body:* {{Set<Int> imos}}
* *After body:* {{Set<String> shipIds}}

h4. Merge single ship

{noformat}POST /processing/recalculate/v2/ship/{shipId}/merge{noformat}

* *Before:* {{/ship/{imo}/merge}}
* *After:* {{/ship/{shipId}/merge}}

h4. Merge batch

{noformat}POST /processing/recalculate/v2/ship/shipId/batch/merge{noformat}

* *Before:* {{/ship/imo/batch/merge}}
* *After:* {{/ship/shipId/batch/merge}}
* *Body changed:* {{List<Int>}} → {{List<String>}}



All of these endpoints need to be changed to use shipId instead of IMO

[*GitHub diff*|https://github.com/teqplay/vesselvoyage-backend/pull/704/changes#diff-ee017febc41f81d20aada93387d58f101746a8ec30b9a16ca12fcc173490f322]



TLDR;

* *IMO has been fully replaced by* {{shipId}} across all recalculation APIs and responses
* All endpoints, request bodies, response models, and error objects now use {{shipId: string}}
* *V1 guarantees are removed* — only {{V2}} is supported
* Batch endpoints now accept {{shipIds: string[]}} *instead of IMOs*
