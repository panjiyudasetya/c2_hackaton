## Description

h2. Description

poma is EOL after building poma-v2. Confirmed with context-mapping that it is not used at all anymore so it is safe to take offline, saves us from having to maintain it.

One note is that the poma****.teqplay.nl urls are pointing to the V2 buckets, so these need to be adjusted in the GitHub environments

h2. Definition of Done

* -DNS records for pomav1****.teqplay.nl are taken offline-
* -GitHub poma-v2 environments now point to the V1 S3, Cloudfront instances-
* Redeploy poma-v2 over the v1 bucket instances
* Repoint DNS for poma****.teqplay.nl to the v1 instances
* Cloudfront instances for poma-v2 (yes you read that right) are taken offline
* S3 buckets for poma-v2 are taken offline
* Deployments are tested and working
