## Description

h2. Description

After showing the completeness metrics of VesselVoyage one of the feedbacks was that it would be very useful to have an option to filter per port. Adding the port unlocode as a tag to the prometheus metric would be very useful.

This would be then used to check to completeness of ports Teqplay has interest in (e.g. USHOU, NLRTM, etc.)
