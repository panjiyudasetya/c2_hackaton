# [TCC-497] Remove uses of ExecutorService::shutdownNow

**URL:** https://teqplaybv.atlassian.net/browse/TCC-497  
**Type:** Bug | **Status:** Done | **Priority:** Highest  
**Reporter:** Michel Wilson | **Assignee:** Joost Dambrink  
**Created:** 2025-10-21 | **Updated:** 2025-10-30  
**Board:** TCC board  
**Parent:** [TCC-152] Production Issues  

## Description

h2. Description

20/10/2025 we had a prio 1 incident with VesselVoyage where it stopped consuming messages after an attempt to restart consuming. Messages could not be processed anymore because the Mongo driver thread was interrupted by a call to {{Thread::interrupt}}. The root cause appears to be a call to {{ExecutorService::shutdownNow}} which, under the hood, calls {{Thread::interrupt}}.

Replace the use of {{shutdownNow}} in {{AisStreamingMessageHandler}} with another mechanism and ensure that it doesn’t use {{Thread::interrupt}} internally.
