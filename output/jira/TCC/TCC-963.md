# [TCC-963] Extend Teqplay API to support getting ship history by IMO for the V1 endpoint

## Description

h2. Description

Currently there is only an endpoint available to fetch ship history by MMSI. This causes issues when a ship changes MMSI, and the data is being fetched in the Timeline for example.

Extend ShipHistory API with the new endpoint and make use of the CSI IMO/MMSI mapping to make the correct underlying calls by MMSI.

* -Changes are shared with consumers (Timeline)-
* -Changes are released-
