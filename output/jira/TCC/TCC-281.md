## Description

h2. Description

Add blackbox testing to AisStream, similar approach how we did this for the StopMonitor where we provide an input (in this case, the raw AIS message) and check the output (the Diff messages).

The following test cases should be covered:

|Check that duplicates AIS messages don’t create duplicate diff messages|AisStream|Send AIS Message|Diff message is received|
| | |Send the same AIS message after 5 minutes|Message is ignored and we dont get any diff message in return|
|Check that duplicates AIS messages that came at the same time doesnt result in duplicate diff message|AisStream|Send the same AIS Message from source A and the same message from source B|Only one Diff message is received|

All the different AIS messages we receive should be tests:

# Position message (type A and B)
# Static message
# Long range message
# … (Probably more, check what we have).

Next to this make sure we test combination of all those types, and different sources we get those message from (e.g. Spire, AISHub, etc.) and have them tested when received out of order.

Timebox to see how many scenarios we can cover, given that there a numerous amount of combinations to test.
