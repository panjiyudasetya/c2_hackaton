## Description

h2. Description

Right now you need the shipId when creating a ticket. Add a new endpoint which can create tickets only by IMO number.

# Ship exists, you take the shipId and create tickets like normal
# Ship doesn’t exist, you do the magic to create a new ship
# Throw exception in controller if IMO change is provided
