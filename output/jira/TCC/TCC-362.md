## Description

h2. Description

Set up a Grafana dashboard where we have all the measurements from the first time where we request to recalculate a port until we finished the recalculation, merged back the data and finished post-processing.

For each measurement have some kind of duration measured using prometheus. The Revents scenario ID as tag into each metric we will measure.

The following needs to be measured:

# Start VesselVoyage recalculation
# Start Revents recalculation
# Start Revents job
# Finish monitor(s)
# Finish Revents job
# Start merging back data
# Finish running post-processing

Each of those have a start and end time, and can be used to calculate a duration.
