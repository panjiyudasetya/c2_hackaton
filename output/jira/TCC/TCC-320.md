# [TCC-320] Anchor area state still stuck for some vessels creating unwanted start events

## Description

h2. Description

An anchor start event was triggered on 2025-07-30 18:34  of an anchorage that is not even close to the ship.

Timeline link:[https://timeline.teqplay.nl/249332000?from=1753829040000&to=1754581440000&URL=https%3A%2F%2Fapi.teqplay.nl%2Fv0&selectedTime=1753893257690&selectedEvent=0565c542-9b28-4d3a-ba0d-5433d2117b89|https://timeline.teqplay.nl/249332000?from=1753829040000&to=1754581440000&URL=https%3A%2F%2Fapi.teqplay.nl%2Fv0&selectedTime=1753893257690&selectedEvent=0565c542-9b28-4d3a-ba0d-5433d2117b89|smart-link] 

h2. Scope

We should never create any start events for ships that are currently not anchoring in said anchor area.

The state should be cleaned up, not containing ships like this anymore when they already left the anchorage for a long time.

h2. Dependencies

This currently has effect on PortReporter where a Customer contacted customer support that we reported that the ship had anchored in Lithuania.

This might have a bigger impact if the fix that has been running is creating more wrong events like this one.
