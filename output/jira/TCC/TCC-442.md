# [TCC-442] Fix an issue in Poma DATA where the Display Name of a port is always blank

## Description

Currently ports that are coming from the WOPs database (external) always have a empty string as display name. This results in PortReporter showing the Unlocode instead of a proper name.

Make a script that we can run on the database, which corrects the display names. If the Port exists in the external database, use the display name that we currently have in the Teqplay database. For example BRRIO → 9994827E0472B19221810C8F0EC1DD15CFBA25DB

Here the display name is set for the Teqplay Database, but the WOP database doesn’t have any display names.

This can be done for all ports, given that no port in the external database has a display name.


{noformat}db.port.find({displayName: { $ne: "" }}){noformat}

This returns 0 records when asked in the {{poma_external}} database.

----

Test on Sandbox, once okay then run the script in Poma DATA and Poma LIVE
