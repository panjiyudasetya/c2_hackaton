## Description

h2. Description

Context mapping has a feature improvement request. They frequently use the template feature to create a new entity based on an old one. But this copies the previous entity 1:1, but usually the name field does need updating.

!afbeelding-20260713-091743.png|width=388,alt="afbeelding-20260713-091743.png"!

After confirming with Kevin, they usually name them e.g. “Berth 1”, “Berth 2”, “Berth 3”. It can be in the middle of the string, but that rarely happens.

So this task should basically mean whenever the user presses the template feature, it should auto increment the number inside the name string by 1. These numbers should be unique by terminal - i.e. if a Berth 3 already exists and user copies from Berth 2, the number increments to the first available number (or +1 of the highest number) inside the terminal.

h2. Definition of Done

* Berth name auto increments by one when clicked the button
* Changes are tested
* Changes are deployed to dev, prod, zandbak
* Context mapping is informed of the new change
