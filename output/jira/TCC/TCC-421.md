## Description

h2. Description

With the newly introduced Journey model we now have two new fields:

* {{eta}}, which is the ETA to the destination port.
* {{etd}}, which is the ETD when we leave the current port we are visiting.

Now that the ETA predictor was a succes we decided to start using the predictions instead of the Platform predictions for the PortcallOne project.

h2. Dependencies

The ETA is needed for the PortcallOne MVP, meaning they will need it this week. Meaning having this done by 18 Sep would be ideal so we still have some time to make fixes if any issues arise.
