# [TCC-268] Creating tickets in CSI via the API with incorrect field types is allowed

**URL:** https://teqplaybv.atlassian.net/browse/TCC-268  
**Type:** Bug | **Status:** To Do | **Priority:** Medium  
**Reporter:** Darius Wattimena | **Assignee:** Unassigned  
**Created:** 2025-07-11 | **Updated:** 2025-08-28  
**Board:** TCC board  
**Parent:** [TCC-152] Production Issues  

## Description

When creating a ticket you need to provide field types. This is an enum, however, when providing incorrect field types it results in the backend accepting this value.

However, this will result in the frontend crashing when trying to open this newly created ticket.

----

DoD:

Adjust the backend so we actually check if the {{changes.fieldType}} provided value is one known in the enum. This way we avoid any creation of incorrect tickets.

Besides this fix any existing tickets on PROD and DATA if they contain any of the wrong field types.

## Subtasks

- [TCC-374] Validate fieldType enum on ticket creation via API (To Do)
- [TCC-375] Identify and correct tickets with invalid field types in PROD and DATA (To Do)
- [TCC-376] Adjust test cases to also include this check (To Do)
