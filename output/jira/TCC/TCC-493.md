## Description

h2. Description

Right now it is really hard to see in the metrics why we are doing bad for a port (e.g. Rotterdam is around 80% for PROD, while other ports are much higher).

Being able to see if we are doing well for the ship categories we are interested in will give a much better view on how complete our data is.
