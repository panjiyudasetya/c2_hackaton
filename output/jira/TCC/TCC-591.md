## Description

The Keycloak token should have the following:

# Realm = {{dev/prod}}
# Audience = {{api}}
# groups contains {{customer_area_monitoring}}

For each customer (user) a {{UserProfile}} should exist. In this profile a {{customerId}} should be available. This id should be the one that is also available in Poma on all the customer area entities.

This UserProfile should be available in the Spring SecurityContextHolder.
