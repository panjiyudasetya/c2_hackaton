## Description

Set up integration test, use BEANR and other schelde ports as areas to test with.

* Test should be done with real AIS trace
* Ports can be adjusted to fit the test

Scenario taking place:

|Send Diff messages:
* AIS points of a vessel reaching the first port but not the second one|Messages are processed|
|Check events|Port start event is created|
|Send Diff messages:
* AIS points of a vessel reaching the second port while not leaving the first one|Messages are processed|
|Check events|Port start event is created for the second one, first one is still not finished|
|Send Diff messages:
* AIS points of a vessel leaving the second port|Messages are processed|
|Check events|Port end event is created for the second one, first one is still not finished|
|Send Diff messages:
* AIS points of a vessel leaving the first port|Messages are processed|
|Check events|Port end event is created for the first one, second one remains finished|
