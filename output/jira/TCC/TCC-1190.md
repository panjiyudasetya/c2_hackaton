## Description

Description
Existing endpoint by ship ids should be extended so you can also provide a IMO or MMSI, for both sides.
Make a reusable ship input model. So we have something like this:
{
  "receiver": {
    "shipId": "something",
    "mmsi": 123456789,
    "imo": 1234567
  },
  "service": {
    "shipId": "something",
    "mmsi": 123456789,
    "imo": 1234567
  },
  "duration": "PT2H30M"
}
When providing the receiver or service vessel, you should only provide 1 of the 3 identifiers. Otherwise throw a bad request exception. Giving a combination of lets say receiver IMO and service vessel as MMSI must be possible. Try to use annotation for validation.
