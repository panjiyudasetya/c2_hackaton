## Description

h2. Description

The auto-opening mechanism for the CSI V2 Timeline links works, but the results are different compared to the manual opening on the page itself.

The behaviour for the auto-opening on the list page should be the same as on the manual opening - with the 2 or more MMSI’s visible in the URL to allow for comparison

h2. Definition of Done

* Auto-opening mechanism on the IMO / MMSI list page opens Timeline links with all relevant MMSI’s
* Manual opening mechanism opens Timeline links with all relevant MMSI’s
* Changes are tested
* Changes are deployed to all environments
* Context mapping informed
