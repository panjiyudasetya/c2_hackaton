# [TCC-297] Adjust Teqplay API endpoint to not use wildcard forwarding

**URL:** https://teqplaybv.atlassian.net/browse/TCC-297

## Description

Currently, wildcard forwarding is used for several API endpoints. To improve routing clarity and maintainability, update the API configuration to explicitly define these forwarded endpoints instead of using wildcard forwarding.

This change should cover the endpoints currently using wildcard forwarding:

* CSI
* ShipHistory
* EventHistory
* Platform
* VesselVoyageV2

----

DoD:

* All endpoints currently using wildcard forwarding are updated to use explicit route definitions.
* API routing is fully functional with no regressions
* Swagger documentation is updated to list all explicitly forwarded endpoints
